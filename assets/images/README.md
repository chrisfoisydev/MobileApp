# Image assets

Drop bitmap assets here.

## becu_debit_card.png

The Manage Card screen (`lib/screens/account_tabs/manage_card_tab.dart`) shows
the BECU debit card. If a file named `becu_debit_card.png` is present in this
folder it is used directly; otherwise a painted replica is rendered as a
fallback.

To use the real artwork, export the `card-image` node (8089:4982) from the
"Accounts-Statements" Figma file as a PNG (≈846×531 @3x) and save it here as
`becu_debit_card.png`.
